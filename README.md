# MRKT ALERT

This is the MRKT ALERT sales presentation (market events in Telegram), a single static HTML page.

## Local preview

```bash
npm install && npm run dev
```

Then open http://127.0.0.1:47291

## Host on Vercel

Import the repo. Set the framework to Other / static, leave the build command empty, and set the output directory to the repo root (`.`).
